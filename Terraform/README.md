# Terraform Tools

Guida ai comandi Terraform per Infrastructure as Code, organizzata dal livello Base al
livello Esperto. Ogni comando in [tools.md](./tools.md) contiene **Comando**,
**Spiegazione** ed **Esempio**.

Prima di usare `apply`, `destroy`, `state rm`, `force-unlock` o modificare un backend,
verifica workspace, account cloud, piano di esecuzione e approvazione del change.
