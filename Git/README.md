# Git Tools

Guida ai comandi Git, dal livello Base al livello Esperto.
Ogni voce di [tools.md](./tools.md) contiene **Comando**, **Spiegazione** ed **Esempio**.

Prima di usare `reset`, `rebase`, `clean` o `push --force-with-lease`, verifica branch e
working tree: possono modificare la cronologia o eliminare lavoro locale.
